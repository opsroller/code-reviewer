# follow-up-review

| Field | Value |
|---|---|
| File | `skills/follow-up-review/SKILL.md` |
| Description | Use after the author responds to a review: re-review the fixes, settle pushback, resolve threads, give the next round's verdict, and open a follow-up task for the owner when a PR merged with findings still open. |
| Used for | After the author responds, or when a PR merged with findings open. |
| Output | Thread statuses, one review for the round, or a follow-up task for the owner. |
| Thread statuses | fixed, answered, declined-accepted, still-open, regressed |
| Merged PR | follow-up task for the owner, one PR comment pointing to it |
| Escalation | direct conversation, then the person the project names |
