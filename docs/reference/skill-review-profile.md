*Reference, for users of the code-reviewer plugin looking up one skill.*

# review-profile

| Field | Value |
|---|---|
| File | `skills/review-profile/SKILL.md` |
| Description | Use when a project has no reviewer notes yet, when they are stale, or when the same finding has appeared in two reviews: builds and maintains the project-specific half of the review as a reference page in the project's docs. |
| Used for | No review notes, stale notes, or a finding seen in two reviews. |
| Output | A reference page of project review notes in the project's docs. |
| Sections | stack, commands, architecture, project rules, security model, budgets, pitfalls, specialists |
| Project rules recorded | license and header convention, documentation framework and layout, commit convention, merge method, PR size limit, required checks, owned paths |
| Pitfall rule | added after the same finding appears in two reviews |
