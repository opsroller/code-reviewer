# docs-review

| Field | Value |
|---|---|
| File | `skills/docs-review/SKILL.md` |
| Description | Use for the documentation pass of every review: check that a change ships with the docs it owes in the same PR, that docs match the tree, and that each touched page follows Diataxis (one kind per page, title patterns, landing pages). |
| Used for | Every PR (docs pass). |
| Output | Doc kinds owed and missing; doc/tree mismatches; per-page Diataxis findings. |
| Compass | action or cognition; study or work |
| Blocking | missing docs for a code, asset or behaviour change; a documented command that fails; a doc that misleads |
| Precedence | the project's own docs guide checklist wins over the plugin's |
